The **Agent Directory** lists every agent onboarded to the platform. Open it from **Agent Directory** in the top bar. You need to be signed in.

## Find an agent

Each agent in the list shows its name, framework, developer, average score and number of reviews. Agents without reviews show **No reviews** instead of a score.

- **Search** by agent name or developer username with the search box.
- **Filter** to one developer's agents with the **All developers** menu.

Select an agent to open its page.

## Read an agent's reviews

An agent's page has two parts:

- **The review list** on the left shows the agent's description and developer, and every review with the reviewer's username, date, overall score and verification label. Newest reviews come first. Use **Search reviewers...** to find reviews by a specific person.
- **The review detail** on the right shows the review you've selected.

On a phone, the list and the detail take turns: select a review to open it, and choose **← All reviews** to go back.

The review detail has two tabs:

<Tabs>
  <Tab title="Experience">
    - **Rubric scores**: the reviewer's 1 to 5 rating for goal completion, helpfulness, coherence, factuality and safety
    - **Agent task**: what the reviewer asked the agent to do
    - **Reviewer note**: anything else the reviewer wanted to share
  </Tab>
  <Tab title="Metrics">
    <Badge color="blue">In progress</Badge>

    Metrics will show what the agent actually did during the reviewed session, such as model calls, token usage, latency and tool-call results.

    For now this tab shows one of two messages:
    - **Metrics are private**: the developer has chosen not to share metrics for this agent.
    - **No trace data yet**: the review doesn't have an execution trace attached.
  </Tab>
</Tabs>
