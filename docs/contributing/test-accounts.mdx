## Trace tokens

Each reviewer also has a seeded personal trace token, so you can send traces right after `supabase db reset` without creating one first. Put it in the agent's `x-rma-trace-token` header (in `examples/course-planner/.env`, the `OTEL_EXPORTER_OTLP_HEADERS` line).

| Username | Trace token |
|---|---|
| demo_reviewer_1 | `rma_trace_demo1_local_seed_only_not_a_real_secret_000` |
| demo_reviewer_2 | `rma_trace_demo2_local_seed_only_not_a_real_secret_000` |

These only exist in the local seed and are public, so never use them anywhere else. Tokens you create yourself on `/review/trace-tokens` work the same way.

## New users

You can also sign up new users locally. Confirmation emails and password-reset codes don't actually send. They show up in [Mailpit](/contributing/local-services).
